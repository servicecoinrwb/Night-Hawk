NOTES

SoundtrackWritten in code, not recorded — a four-bar minor progression sequenced live in Web Audio. Tempo and filter cutoff track your speed, and the layers stack as hostiles arrive. No audio files, nothing to load.
Built withTwo single HTML files. three.js r128 off a CDN, everything else hand-rolled. No build step, no framework, no dependencies to install — open the file and it runs.
ScoresBest score and longest run are held in memory for the session only. They reset when you reload.
